# 휘발성 메모리 백업소 (배포 저장소)

<https://dev.route50.kr/> 블로그의 배포 결과물을 두는 저장소입니다.

경력만큼 잊는 것도 쌓이는 개발자의 휘발되는 기억을 붙잡아 두는 학습 노트를 [Hugo](https://gohugo.io/)와 [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 테마로 만들어 GitHub Pages로 공개합니다.

## 사이트

| 항목 | 내용 |
| --- | --- |
| 주소 | <https://dev.route50.kr/> |
| 글 목록 | <https://dev.route50.kr/posts/> |
| RSS | <https://dev.route50.kr/index.xml> |
| 호스팅 | GitHub Pages (`main` 브랜치, `/` 루트) |
| 생성기 | Hugo Extended, PaperMod 테마 |

다른 사람이 만든 사진과 자료는 각 글의 캡션과 참고 자료에 출처와 라이선스를 적었습니다.
