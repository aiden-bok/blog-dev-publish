2. DBeaver 설치와 기본 사용법

DBeaver Community를 Windows, macOS, Linux에 설치하는 방법과 새 연결 만들기, SQL 실행 단축키, 결과 내보내기까지 기본 사용법을 공식 문서 기준으로 정리했습니다.

DBeaver Community는 운영체제별 설치 파일을 받아 실행하면 설치가 끝납니다. 설치 후에는 Ctrl+Shift+N으로 새 연결 마법사를 열어 DB 종류를 고르고 접속 정보를 입력한 뒤 Test Connection으로 확인하면 쿼리를 실행할 수 있습니다. 이 글은 DBeaver Community 26.2.4(2026-11-01 공개) 공식 문서를 2026-11-04에 확인해 정리했습니다.

작성 환경에서는 화면이 있는 DBeaver를 실행할 수 없었습니다. 설치 명령과 단축키는 공식 문서에서 가져왔고 직접 실행해 확인하지 못했으며, 화면 캡처와 실행 결과도 싣지 않았습니다. 도구 선택은 1. 데이터베이스 관리 툴 비교와 DBeaver를 참고하세요.

설치 전에 확인할 것#

DBeaver Community는 Windows 10 이상(Windows Server 2016 이상), macOS 11 이상, 대부분의 최신 Linux 배포판을 지원합니다. (Installation) 하드웨어는 Windows(x86, ARM), macOS(Apple Silicon, Intel), Linux(x86, ARM)용이 따로 있어서 내 CPU에 맞는 파일을 골라야 합니다. DBeaver는 Java 25 이상이 필요하지만 모든 배포판에 JDK(Java Development Kit: 자바 개발 키트)인 OpenJDK 25가 들어 있으므로 Java를 따로 설치하지 않아도 됩니다. (Download)

Windows에 설치하기#

Windows는 설치 프로그램(EXE)을 실행해 화면 안내를 따르는 방법이 권장됩니다. 필요한 구성요소가 모두 들어 있고 이미 설치된 DBeaver가 있으면 업그레이드합니다. 설치 없이 쓰려면 ZIP을 풀어 dbeaver 실행 파일을 열며, 새 버전으로 바꿀 때는 이전에 푼 폴더를 지운 뒤 다시 풉니다. (Installation) 다운로드 페이지는 Microsoft Store와 Chocolatey도 안내하며, Chocolatey 명령은 아래와 같습니다. (Download)

choco install dbeaver

macOS에 설치하기#

macOS는 DMG를 받아 설치 안내를 따르거나 Homebrew(macOS용 패키지 관리자)의 Cask를 씁니다. (Download) 설치 프로그램에는 DBeaver만 쓰는 JDK가 들어 있습니다. (Installation)

brew install --cask dbeaver-community

Linux에 설치하기#

Linux는 패키지 형식에 맞는 명령을 씁니다. Debian과 Ubuntu 계열은 DEB(Debian 패키지), Red Hat 계열은 RPM(RPM 패키지)이고, 배포판과 관계없이 Snap(Canonical의 패키지 형식)도 쓸 수 있습니다. (Installation) <version>은 받은 파일의 버전으로 바꿉니다.

# DEB (Debian, Ubuntu)
sudo dpkg -i dbeaver-<version>.deb

# RPM (설치는 -ivh, 업그레이드는 -Uvh)
sudo rpm -ivh dbeaver-<version>.rpm

# Snap
snap install dbeaver-ce --stable

DEB와 RPM으로 설치한 뒤에는 터미널에서 dbeaver &로 실행합니다. 다운로드 페이지에는 TAR.GZ, Flatpak, Debian 계열용 apt 저장소도 있습니다. (Download)

데이터베이스에 연결하기#

연결을 만드는 순서는 마법사를 열고, 드라이버를 고르고, 접속 정보를 넣고, 시험한 뒤 저장하는 것입니다. 메인 툴바나 Connections 뷰의 New Connection Wizard 버튼을 누르거나 Ctrl+Shift+N을 누르면 마법사가 열립니다. (Create Connection)

드라이버 목록에서는 Search로 DB나 드라이버를 찾을 수 있고 Title이나 Score로 정렬합니다. 접속 정보 화면의 기본 항목은 다음과 같습니다. (Create Connection)

  • Host: DB 서버 주소
  • Port: 접속 포트
  • Database: 접속할 데이터베이스 이름
  • Username, Password: 인증 정보

SQLite 같은 내장형 드라이버는 호스트와 포트 대신 DB 파일 경로를 받을 수 있습니다. Test Connection으로 확인한 뒤 Finish를 누르면 Connections 트리에 연결이 나타납니다.

운영 DB를 다룰 때의 연결 유형#

연결 설정의 General 항목에는 Connection type이 있어서 Development(기본값), Test, Production 중에서 고릅니다. 같은 항목에서 읽기 전용, 데이터 수정, 구조 변경, 스크립트 실행, 가져오기를 막는 보안 옵션도 지정합니다. (Create Connection) 운영 서버에 접속하는 연결은 읽기 전용으로 만들어 두면 실수로 데이터를 지우는 일을 줄일 수 있습니다.

SQL 실행하기#

SQL(Structured Query Language: 데이터베이스 질의 언어) 편집기는 연결을 선택한 상태에서 F3(Choose SQL Script 창에서 New Script)이나 F4(기존 스크립트 열기)로 엽니다. (SQL Editor) 실행 단축키는 다음과 같습니다. (SQL Execution)

동작단축키
커서 위치 또는 선택한 SQL 한 문장 실행Ctrl+Enter
스크립트 전체 실행Alt+X
새 탭에서 SQL 실행Ctrl+\
스크립트 실행, 문장마다 결과 탭 분리Ctrl+Alt+Shift+X

결과 패널은 Ctrl+6으로 보이거나 숨기고, Ctrl+Shift+T로 최대화하며, Ctrl+Alt+T로 스크립트와 결과 사이를 오갑니다. (SQL Editor) 아래는 연습용 쿼리입니다. 이 쿼리는 이 글을 쓰는 환경에서 실행해 보지 못했으므로, 연습용 DB에서 먼저 돌려 보세요.

SELECT u.name, COUNT(o.id) AS order_count
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id, u.name
ORDER BY order_count DESC;

결과를 파일로 내보내기#

결과 내보내기는 Data Export 마법사로 합니다. 시작 위치는 Connections 트리의 테이블 우클릭 Export Data, SQL 스크립트의 Execute > Export from Query, 결과 그리드 우클릭 Export data 세 곳입니다. 형식은 CSV, JSON, SQL, XML, XLSX, HTML, Markdown, TXT 등에서 고르고, 이어서 추출 옵션, 형식 설정, 출력 위치를 정한 뒤 Finish를 누릅니다. 내보내기는 백그라운드에서 실행되어 그동안 다른 작업을 할 수 있고, 설정을 작업(task)으로 저장해 다시 쓸 수도 있습니다. (Data export)

ER 다이어그램으로 테이블 관계 보기#

ER 다이어그램(Entity Relationship Diagram: 개체 관계 다이어그램)은 테이블과 컬럼, 테이블 사이의 관계를 그림으로 보여 줍니다. 컬럼은 전체, 키만, 기본 키만, 표시 안 함으로 고를 수 있고 관계선 표기법은 IDEF1X(기본값), Bachman, Crow’s Foot 중에서 정합니다. (How to use Diagrams) 다이어그램을 직접 고치는 편집 모드는 Enterprise와 Ultimate 버전에서만 쓸 수 있습니다. (Edit mode)

용어 설명#

JDK#

Java Development Kit. Java 프로그램을 실행하고 만드는 데 필요한 도구 모음입니다. OpenJDK는 그 오픈소스 구현입니다. (OpenJDK)

Homebrew#

macOS와 Linux에서 프로그램을 명령어로 설치하고 관리하는 패키지 관리자입니다. 화면이 있는 앱은 Cask로 설치합니다. (Homebrew)

DEB#

Debian과 Ubuntu 계열 배포판의 패키지 파일 형식(.deb)입니다. dpkg로 설치합니다. (Debian FAQ)

RPM#

Red Hat 계열 배포판의 패키지 파일 형식(.rpm)이자 설치 도구 이름입니다. (rpm.org)

Snap#

Canonical이 만든 Linux 패키지 형식입니다. snap 명령으로 설치합니다. (Snapcraft)

SQL#

Structured Query Language. 관계형 데이터베이스에서 데이터를 조회하고 고치는 표준 질의 언어입니다. (PostgreSQL SQL 문서)

ER 다이어그램#

Entity Relationship Diagram. 테이블(개체)과 그 사이의 관계를 그린 도표입니다. DBeaver는 IDEF1X, Bachman, Crow’s Foot 표기법을 지원합니다. (How to use Diagrams)
