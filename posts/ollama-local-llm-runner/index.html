Ollama는 LLM(Large Language Model: 대규모 언어 모델)을 내 컴퓨터에서 내려받아 실행해 주는 도구입니다. 설치하면 localhost:11434 포트에서 서버가 돌고, ollama run 모델이름 한 줄로 대화를 시작할 수 있으며, 같은 서버에 REST API(Representational State Transfer API: HTTP로 주고받는 인터페이스)로 요청을 보내 내 프로그램에서도 모델을 쓸 수 있습니다.

이 글은 Ollama 공식 문서를 기준으로 정리했고, 설치 방법과 명령어는 2026-11-02에 문서를 확인한 내용입니다. 글을 쓰는 환경에서 직접 실행해 확인한 것은 아니어서 실행 결과 출력은 싣지 않았습니다. 모델 크기와 VRAM 계산 같은 배경은 로컬 LLM 개발을 시작할 때 알아야 할 핵심 지식에 있습니다.

Ollama는 어떤 구조로 동작하는가#

Ollama는 백그라운드 서버와 그 서버에 요청을 보내는 클라이언트로 나뉩니다. ollama run 같은 CLI(Command Line Interface: 명령줄 도구) 명령도 같은 서버에 요청을 보내는 클라이언트이고, curl이나 직접 만든 앱도 같은 방식으로 서버를 씁니다. 서버는 디스크에 받아 둔 모델을 요청이 올 때 메모리에 올려 응답을 만들고, 기본값으로 마지막 사용 후 5분 동안 메모리에 유지합니다. (Ollama FAQ)

서버는 기본적으로 127.0.0.1에서만 요청을 받습니다. 다른 컴퓨터에서 접속하게 하려면 OLLAMA_HOST 환경 변수를 0.0.0.0:11434처럼 바꿔야 하며, 인증이 없는 로컬 서버를 외부에 열게 되므로 방화벽 설정을 함께 확인해야 합니다. (Ollama FAQ)

운영체제별 설치 방법#

설치 방법은 운영체제마다 다르지만, 끝나면 모두 ollama 명령을 쓸 수 있습니다. 설치 파일과 명령은 ollama.com/download에서 받습니다.

macOS#

macOS Sonoma(14) 이상이 필요합니다. Apple Silicon(M 시리즈)은 CPU와 GPU를 모두 쓰고, Intel Mac은 CPU만 씁니다. ollama.dmg를 열어 Ollama 앱을 Applications로 옮기고 실행하면 됩니다. 처음 실행할 때 ollama 명령이 PATH에 없으면 /usr/local/bin에 링크를 만들어도 되는지 묻습니다. 모델은 ~/.ollama에 저장되고, 로그는 ~/.ollama/logs의 app.log와 server.log에 남습니다. (Ollama macOS 문서)

Windows#

Windows 10 22H2 이상이 필요하고, NVIDIA GPU는 드라이버 551.61 이상이어야 합니다. 설치 파일 OllamaSetup.exe를 받아 실행하거나, PowerShell에서 아래 명령을 씁니다. 설치에 관리자 권한이 필요 없고 기본으로 사용자 홈 폴더에 설치됩니다. 바이너리에 4GB 이상, 모델에 수십에서 수백 GB가 필요할 수 있으니 디스크 여유를 확인하세요. 모델 저장 위치를 바꾸려면 사용자 환경 변수 OLLAMA_MODELS를 설정한 뒤 트레이 앱을 다시 실행합니다. (Ollama Windows 문서)

irm https://ollama.com/install.ps1 | iex

Linux#

Linux는 설치 스크립트 한 줄로 설치합니다. 스크립트는 인터넷에서 받은 코드를 실행하므로, 내용이 궁금하면 먼저 내려받아 읽어 본 뒤 실행해도 됩니다.

curl -fsSL https://ollama.com/install.sh | sh

NVIDIA는 CUDA 드라이버를 설치하고 nvidia-smi로 확인해야 GPU를 씁니다. 스크립트 대신 ollama-linux-amd64.tar.zst를 /usr에 풀어 수동으로 설치할 수도 있고, 이 경우 ollama serve로 서버를 직접 띄웁니다. systemd 서비스로 등록했다면 journalctl -e -u ollama로 로그를 봅니다. 업그레이드는 설치 스크립트를 다시 실행하면 됩니다. (Ollama Linux 문서)

설치가 끝났으면 터미널에서 ollama -v로 버전이 나오는지 확인합니다.

모델을 내려받고 실행하는 기본 명령#

모델은 ollama pull로 내려받고 ollama run으로 대화합니다. 공식 퀵스타트의 예시는 Gemma 4 E2B 모델이고, 크기는 약 7.2GB이며 8GB 이상의 VRAM(Video RAM: GPU 전용 메모리)이나 통합 메모리에서 잘 돌아간다고 안내합니다. (Ollama Quickstart)

ollama pull gemma4:e2b
ollama run gemma4:e2b

ollama run은 모델이 없으면 먼저 내려받고, 대화 프롬프트를 엽니다. 대화에서 나올 때는 /bye를 입력합니다. 모델 이름 뒤의 :e2b는 태그로, 같은 모델의 크기나 양자화 변형을 가르는 이름입니다. 태그를 생략하면 기본 태그를 받습니다. 어떤 모델이 있는지는 Ollama 모델 라이브러리에서 찾습니다.

ollama run 모델이름 "질문"처럼 프롬프트를 뒤에 붙이면 대화 화면을 열지 않고 한 번만 답을 받을 수 있어, 쉘 스크립트에서 쓰기 편합니다.

자주 쓰는 관리 명령#

명령하는 일
ollama pull 모델모델 내려받기
ollama run 모델모델 실행과 대화
ollama ls내려받은 모델 목록
ollama ps지금 메모리에 올라온 모델
ollama stop 모델실행 중인 모델을 메모리에서 내림
ollama rm 모델모델 삭제
ollama create -f ModelfileModelfile로 맞춤 모델 만들기

(Ollama CLI 문서, 2026-11-02 확인)

ollama ps의 PROCESSOR 열에는 모델이 GPU, CPU, 또는 둘로 나뉘어 돌고 있는지가 표시됩니다. 응답이 예상보다 느릴 때 모델이 GPU에 다 올라갔는지 확인하는 데 쓸 수 있습니다. (Ollama FAQ)

모델 저장 위치와 용량 관리#

모델 파일은 크기가 커서 디스크를 금방 채웁니다. 기본 저장 위치는 macOS ~/.ollama/models, Linux /usr/share/ollama/.ollama/models, Windows C:\Users\<사용자 이름>\.ollama\models입니다. 위치를 바꾸려면 OLLAMA_MODELS 환경 변수를 설정합니다. 안 쓰는 모델은 ollama ls로 확인한 뒤 ollama rm으로 지웁니다. (Ollama FAQ)

REST API로 호출하는 방법#

Ollama 서버에 HTTP 요청을 보내면 프로그램에서 모델을 호출할 수 있습니다. 로컬 서버 주소는 http://localhost:11434이고, 로컬 요청에는 API 키가 필요 없습니다. (Ollama API 문서)

대화형 요청: /api/chat#

/api/chat은 messages 배열로 대화 기록을 보내는 엔드포인트입니다. 공식 문서의 예시는 아래와 같고, 답변은 응답의 message.content에 들어 있습니다. "stream": false를 넣어야 응답이 한 덩어리로 옵니다. (Ollama Quickstart)

curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemma4:e2b",
    "messages": [{"role": "user", "content": "Say hello in one sentence."}],
    "stream": false
  }'

요청하기 전에 model에 적은 모델을 ollama pull로 받아 두어야 합니다. 이 글에서는 이 요청을 실행하지 않았으므로 응답 예시는 넣지 않았습니다.

단일 프롬프트 요청: /api/generate#

/api/generate는 대화 기록 없이 프롬프트 하나에 답을 받는 엔드포인트입니다. 요청에는 model이 필수이고 prompt, system, format, keep_alive, options(temperature, num_ctx 등)를 더할 수 있습니다. 응답의 response 필드에 생성된 텍스트가 들어 있고, 소요 시간은 나노초 단위로 total_duration, eval_duration 등에 담깁니다. (Ollama generate 문서)

curl http://localhost:11434/api/generate \
  -d '{
    "model": "gemma4:e2b",
    "prompt": "Why is the sky blue?",
    "stream": false
  }'

스트리밍 응답을 받을 때 주의할 점#

/api/generate는 stream의 기본값이 true입니다. 그래서 "stream": false를 빼면 응답이 한 덩어리가 아니라 줄마다 JSON 하나인 NDJSON(Newline Delimited JSON: 줄바꿈으로 구분한 JSON)으로 옵니다. 각 줄의 response에는 일부 텍스트가 들어 있고 "done": false이며, 마지막 줄에서 "done": true와 "done_reason": "stop"이 옵니다. (Ollama Streaming 문서)

이 때문에 응답 전체를 JSON.parse 같은 함수에 그대로 넣으면 오류가 납니다. 글자가 나오는 대로 화면에 보여 주려면 스트리밍으로 받아 줄 단위로 처리하고, 단순히 결과 문자열이 필요하면 "stream": false를 쓰는 것이 간단합니다.

OpenAI, Anthropic 호환 엔드포인트#

Ollama는 OpenAI Chat Completions(/v1/chat/completions), OpenAI Responses(/v1/responses), Anthropic Messages(/v1/messages) 형식의 요청도 받습니다. 이미 OpenAI SDK로 만든 코드가 있으면 기본 주소(base URL)를 http://localhost:11434/v1로 바꾸는 것만으로 로컬 모델을 시험해 볼 수 있습니다. Anthropic 형식은 anthropic-version: 2023-06-01 헤더가 필요합니다. (Ollama Quickstart, Ollama API 문서)

모델 이름과 요구 사양은 2026-11-02 기준 문서의 내용이라 바뀔 수 있으니, 설치 전에 공식 문서를 한 번 더 확인하세요.

용어 설명#

LLM#

Large Language Model(대규모 언어 모델). 많은 텍스트로 학습해 문장을 이해하고 생성하는 모델입니다. (Ollama 모델 라이브러리)

REST API#

Representational State Transfer API. HTTP 요청과 응답으로 기능을 주고받는 인터페이스입니다. Ollama는 JSON 본문을 쓰는 HTTP 엔드포인트를 제공합니다. (Ollama API 문서)

CLI#

Command Line Interface(명령줄 인터페이스). 터미널에 명령어를 입력해 프로그램을 쓰는 방식입니다. Ollama의 CLI 명령은 CLI Reference에 있습니다.

VRAM#

Video RAM. 그래픽 카드에 달린 전용 메모리입니다. 모델이 이 메모리에 다 올라가야 GPU로 빠르게 실행됩니다. (Ollama Quickstart)

NDJSON#

Newline Delimited JSON. JSON 객체를 한 줄에 하나씩 이어 붙인 형식입니다. Ollama의 스트리밍 응답이 이 형식이고, 콘텐츠 유형은 application/x-ndjson입니다. (Ollama Streaming 문서)
