3. ChatGPT를 쓸 때 주의할 점

ChatGPT에 민감한 정보를 넣기 전에 알아야 할 데이터 사용 설정, 임시 채팅, 피드백 예외와 답변을 검증하는 방법을 OpenAI 공식 문서 기준으로 정리했습니다.
2026년 11월 5일 · 3 분 · 백업 담당자

개인 계정의 ChatGPT는 기본 설정에서 대화가 모델 개선에 쓰일 수 있으므로, 개인정보와 회사 기밀은 넣지 않는 것이 원칙입니다. 학습에 쓰이지 않게 하려면 Settings의 Data controls에서 Improve the model for everyone을 끕니다. 그래도 답변에 남긴 피드백은 예외입니다. 이 글은 1. 일반 사용자를 위한 ChatGPT 프롬프트와 설정의 후속으로, 2026-11-05에 확인한 OpenAI 공식 문서를 기준으로 합니다. 설정 이름과 위치는 바뀔 수 있습니다.

내 대화가 모델 학습에 쓰이지 않게 하려면#

개인 요금제에서는 Settings의 Data controls에서 Improve the model for everyone을 끄거나 OpenAI Privacy Portal에서 Do not train on my content를 선택하면 됩니다. 한 번 끄면 계정 전체에 적용됩니다. (How your data is used to improve model performance)

예외가 두 가지 있습니다. 답변에 엄지 위나 아래로 피드백을 보내면 그 대화 전체가 모델 개선에 쓰일 수 있습니다. 또 이 설정이 켜져 있으면 OpenAI 지원팀과 나눈 대화도 쓰일 수 있습니다. 반대로 임시 채팅은 임시 상태인 동안 모델 개선에 쓰이지 않고, 저장하면 일반 채팅이 되어 설정을 따릅니다. 같은 문서에 따르면 ChatGPT Business, Enterprise, Edu와 API(Application Programming Interface: 응용 프로그램 인터페이스)의 입력과 출력은 기본적으로 모델 개선에 쓰이지 않습니다. 회사에서 쓴다면 개인 계정이 아니라 회사가 계약한 요금제로 쓰는 것이 안전합니다.

넣으면 안 되는 정보#

설정을 꺼도 내용이 서비스에 전송된다는 사실은 달라지지 않습니다. 아래는 이 글이 권하는 기준이며 OpenAI 문서의 규정은 아닙니다.

  • 주민등록번호, 계좌번호 같은 개인정보
  • 비밀번호, API 키, 토큰 (코드나 로그를 붙이기 전에 지웁니다)
  • 계약서, 고객 목록, 미공개 실적 같은 회사 기밀
  • 회사의 정보 보안 규정이 외부 AI 서비스 사용을 금지한 자료

붙여 넣기 전에 홍길동을 고객A로, 실제 도메인을 example.com으로 바꾸는 습관만으로도 위험이 줄어듭니다.

답변이 틀릴 수 있다는 전제로 검증하기#

ChatGPT는 그럴듯한 문장을 만들 뿐, 사실을 보증하지 않습니다. OpenAI의 프롬프트 가이드는 검증 방법으로 출처나 원문 인용 요구, 불확실한 내용의 (needs verification) 표시, 가정 나열을 권합니다. 정답을 이미 아는 질문 5~10개로 답을 비교해 보는 방법도 제안합니다. (ChatGPT Enterprise Prompting Guide) 법률, 의료, 금융처럼 결과가 큰 영역은 답변을 전문가나 공식 자료로 다시 확인합니다. 숫자, 날짜, 인용문, 링크는 특히 원본과 대조합니다.

방금 답변에서 사실로 단정한 문장을 목록으로 뽑고,
각 문장의 근거가 내가 준 자료에 있는지 표시해 주세요.
자료에 없는 것은 (needs verification)으로 표시해 주세요.

저장된 메모리와 지침도 점검하기#

메모리와 Custom Instructions는 이후 대화에 영향을 줍니다. 잘못 저장된 내용이 있으면 답이 계속 어긋나므로 가끔 확인합니다. 새 주제를 완전히 분리하고 싶으면 프로젝트 전용 메모리나 임시 채팅을 씁니다. 자세한 차이는 1편의 반복해서 쓰는 지침은 어디에 저장할까 절에 있습니다.
